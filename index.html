HTML-Viewer für PowerPoint

Bindet eine lokale HTML-Datei (z. B. einen ECharts-Export) interaktiv in eine PowerPoint-Folie ein. Die Datei wird in der .pptx gespeichert – sie wird nirgendwo hochgeladen.

Schritt 1: Manifest herunterladen

Die Datei manifest.xml sagt PowerPoint, wo das Add-in liegt. Sie ist bereits auf diese Adresse eingestellt:

Schritt 2 (Windows): Add-in in PowerPoint bekannt machen

  1. Ordner anlegen, z. B. C:\PowerPoint-Addins, und manifest.xml hineinlegen.
  2. Ordner freigeben: Rechtsklick → Eigenschaften → Freigabe → Freigeben… → Freigeben. Die angezeigte Netzwerkadresse notieren, z. B. \\MEIN-PC\PowerPoint-Addins.
  3. PowerPoint: Datei → Optionen → Trust Center → Einstellungen für das Trust Center → Vertrauenswürdige Add-In-Kataloge.
  4. Netzwerkadresse bei Katalog-URL eintragen → Katalog hinzufügen → Haken bei Im Menü anzeigen → OK. PowerPoint schließen und neu öffnen.

Schritt 2 (Mac): Add-in in PowerPoint bekannt machen

  1. Im Finder Cmd + Shift + G drücken und eingeben:
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef
    Falls der Ordner wef fehlt: im Ordner Documents neu anlegen.
  2. manifest.xml in diesen Ordner kopieren.
  3. PowerPoint schließen und neu öffnen.

Schritt 3: Verwenden

  1. Windows: Einfügen → Add-ins → Meine Add-ins → Freigegebener Ordner → HTML-Viewer.
    Mac: Start → Add-ins (bzw. Einfügen → Add-ins) → HTML-Viewer.
  2. Den Rahmen auf die gewünschte Größe ziehen und HTML-Datei wählen … klicken.
  3. Präsentation speichern. In der Bildschirmpräsentation ist die Darstellung voll interaktiv.

Das Add-in benötigt beim Öffnen der Präsentation eine Internetverbindung (es wird von dieser Adresse geladen). Wer die .pptx öffnet, braucht das Add-in ebenfalls (Schritt 2) – sonst erscheint statt der Grafik ein Platzhalter.
