ECharts aus KNIME in PowerPoint

Du kennst den Generic ECharts View in KNIME? Mit diesen zwei Erweiterungen nimmst du deine ECharts-Diagramme mit in PowerPoint – und sie bleiben dort interaktiv. Du brauchst keine Programmierkenntnisse, folge einfach den Schritten.

Hinweis: Beide Erweiterungen sind ein KI-gestütztes Eigenprojekt und kein offizielles Produkt von KNIME oder Microsoft. Sie werden so zur Verfügung gestellt, wie sie sind – ohne Support. Die Nutzung erfolgt auf eigene Verantwortung.

So funktioniert es

Du brauchst zwei Erweiterungen. Sie arbeiten zusammen wie ein Fotoapparat und ein Bilderrahmen:

  1. KNIME-Node „ECharts View & Export“ – erstellt dein Diagramm und speichert es als Datei (z. B. diagramm.html). Der Fotoapparat.
  2. PowerPoint-Add-in „HTML-Viewer“ – zeigt diese Datei interaktiv in deiner Folie an. Der Bilderrahmen.

Ohne den KNIME-Node hast du keine Datei. Ohne das Add-in kann PowerPoint die Datei nicht anzeigen. Deshalb installierst du beide – einmalig, in dieser Reihenfolge:

Teil 1 KNIME-Node installieren  →  Teil 2 PowerPoint-Add-in installieren  →  Teil 3 verwenden

Teil 1 – KNIME-Node Teil 2 – PowerPoint-Add-in (Windows) Teil 2 – PowerPoint-Add-in (Mac) Teil 3 – Verwenden

Teil 1 – KNIME-Node „ECharts View & Export“ installieren

Einmalig pro Computer. Voraussetzung: KNIME Analytics Platform 5.12.

Schritt 1: Datei herunterladen

Die Datei ist ca. 660 MB groß – der Download kann einige Minuten dauern.

KNIME-Erweiterung herunterladen (.zip)

Wichtig: Die ZIP-Datei nicht entpacken. Verschiebe sie in einen Ordner, in dem sie bleiben darf, z. B. Dokumente.

  1. KNIME öffnen.
  2. Einstellungen öffnen:
    Windows: Menü ☰ (oben rechts) → Preferences
    Mac: Menü KNIME (oben links in der Menüleiste) → Settings…
  3. Links Install/Update aufklappen → Available Software Sites.
  4. Rechts Add… → Archive… → die ZIP-Datei auswählen → Öffnen.
  5. Bei Name „ECharts Export“ eintragen → Add → Apply and Close.
  6. Menü ☰ → Install Extensions… (Mac: Menü File → Install KNIME Extensions…).
  7. Im Suchfeld ECharts eingeben → Haken bei ECharts View & Export → Next → Next.
  8. I accept the terms … auswählen → Finish.
  9. Es erscheint ein Hinweis auf „unsigned content“ → Install anyway. (Normal – die Erweiterung ist nicht von KNIME selbst signiert.)
  10. Auf Restart Now klicken. Nach dem Neustart richtet KNIME die Erweiterung ein (kann einige Minuten dauern).

Fertig, wenn du im Node-Repository unter ECharts Export den Node ECharts View & Export findest.

Teil 2 – PowerPoint-Add-in „HTML-Viewer“ installieren: Windows

Nur wenn du einen Windows-PC hast – mit Mac geht es weiter unten. Einmalig pro Computer. Voraussetzung: PowerPoint aus Microsoft 365.

Schritt 1: Installationsdatei herunterladen

Installationsdatei herunterladen
  1. PowerPoint schließen.
  2. Die heruntergeladene Datei HTML-Viewer-installieren-Windows.cmd doppelklicken (du findest sie im Ordner Downloads).
  3. Falls Windows „Der Computer wurde durch Windows geschützt“ meldet: Weitere Informationen → Trotzdem ausführen. (Die Datei trägt nur das Add-in in PowerPoint ein – nur für dein Benutzerkonto, ohne Administratorrechte.)
  4. Es öffnet sich ein schwarzes Fenster mit „Fertig!“ → eine beliebige Taste drücken.
  5. PowerPoint öffnen → Reiter Start → ganz rechts Add-Ins → Weitere Add-Ins.
  6. Oben Meine Add-Ins wählen. Unter Entwickler-Add-Ins steht HTML-Viewer → anklicken → Hinzufügen.

Wieder entfernen: Entfernen-Datei herunterladen und doppelklicken.

Teil 2 – PowerPoint-Add-in „HTML-Viewer“ installieren: Mac

Nur wenn du einen Mac hast. Einmalig pro Computer. Voraussetzung: PowerPoint aus Microsoft 365.

Schritt 1: Add-in-Datei herunterladen

manifest.xml herunterladen
  1. PowerPoint beenden (Menü PowerPoint → PowerPoint beenden).
  2. Den Finder öffnen und Cmd + Shift + G drücken.
  3. Diese Zeile einfügen und Enter drücken:
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  4. Gibt es dort einen Ordner wef? Wenn nicht: Rechtsklick → Neuer Ordner → Name wef.
  5. Ordner wef öffnen und die Datei manifest.xml aus Downloads hineinziehen.
  6. PowerPoint öffnen → Reiter Start → Add-Ins → HTML-Viewer.

Teil 3 – Verwenden

  1. In KNIME: Node ECharts View & Export in den Workflow ziehen und an deine Tabelle anschließen.
  2. Doppelklick auf den Node → deinen ECharts-Code einfügen (genau wie im Generic ECharts View) → bei Export-Datei einen Pfad angeben, z. B. C:\Export\diagramm.json → Haken bei HTML-Datei speichern lassen → OK.
  3. Node ausführen. Neben der JSON-Datei liegt jetzt diagramm.html.
  4. In PowerPoint: Folie öffnen → Start → Add-Ins → HTML-Viewer.
  5. Rahmen auf die gewünschte Größe ziehen → HTML-Datei wählen … → diagramm.html auswählen.
  6. Präsentation speichern. In der Bildschirmpräsentation (F5) ist das Diagramm interaktiv.

Gut zu wissen: Das Diagramm wird in deiner .pptx gespeichert und nirgendwo hochgeladen. Beim Öffnen der Präsentation braucht PowerPoint Internet, um das Add-in zu laden. Wer deine Präsentation öffnet, braucht ebenfalls das Add-in (Teil 2) – sonst erscheint ein Platzhalter.

ECharts from KNIME in PowerPoint

You know the Generic ECharts View in KNIME? With these two extensions you take your ECharts visualizations into PowerPoint – and they stay interactive there. No coding needed, just follow the steps.

Please note: Both extensions are an AI-assisted personal project and not an official product of KNIME or Microsoft. They are provided as they are – without support. Use at your own risk.

How it works

You need two extensions. They work together like a camera and a picture frame:

  1. KNIME node “ECharts View & Export” – creates your chart and saves it as a file (e.g. chart.html). The camera.
  2. PowerPoint add-in “HTML-Viewer” – shows this file interactively in your slide. The picture frame.

Without the KNIME node you have no file. Without the add-in PowerPoint cannot show the file. That’s why you install both – once, in this order:

Part 1 install the KNIME node  →  Part 2 install the PowerPoint add-in  →  Part 3 use it

Part 1 – KNIME node Part 2 – PowerPoint add-in (Windows) Part 2 – PowerPoint add-in (Mac) Part 3 – Use it

Part 1 – Install the KNIME node “ECharts View & Export”

Once per computer. Requires KNIME Analytics Platform 5.12.

Step 1: Download the file

The file is about 660 MB – the download may take a few minutes.

Download the KNIME extension (.zip)

Important: do not unzip the file. Move it to a folder where it can stay, e.g. Documents.

  1. Open KNIME.
  2. Open the settings:
    Windows: menu ☰ (top right) → Preferences
    Mac: menu KNIME (top left in the menu bar) → Settings…
  3. On the left, expand Install/Update → Available Software Sites.
  4. On the right, Add… → Archive… → select the ZIP file → Open.
  5. Enter “ECharts Export” as Name → Add → Apply and Close.
  6. Menu ☰ → Install Extensions… (Mac: menu File → Install KNIME Extensions…).
  7. Type ECharts into the search field → tick ECharts View & Export → Next → Next.
  8. Select I accept the terms … → Finish.
  9. A message about “unsigned content” appears → Install anyway. (This is normal – the extension is not signed by KNIME itself.)
  10. Click Restart Now. After the restart KNIME sets up the extension (this can take a few minutes).

Done when you find the node ECharts View & Export in the node repository under ECharts Export.

Note: the node’s settings dialog is in German. The fields you need are ECharts-Code (your code), Export-Datei (.json) (export file) and Zusätzlich eigenständige HTML-Datei speichern (also save an HTML file).

Part 2 – Install the PowerPoint add-in “HTML-Viewer”: Windows

Only if you have a Windows PC – for Mac see below. Once per computer. Requires PowerPoint from Microsoft 365.

Step 1: Download the setup file

Download the setup file
  1. Close PowerPoint.
  2. Double-click the downloaded file HTML-Viewer-installieren-Windows.cmd (you find it in your Downloads folder).
  3. If Windows says “Windows protected your PC”: More info → Run anyway. (The file only registers the add-in in PowerPoint – for your user account only, no admin rights.)
  4. A black window opens and says “Fertig!” (done) → press any key.
  5. Open PowerPoint → tab Home → far right Add-ins → More Add-ins.
  6. Choose My Add-ins at the top. Under Developer Add-ins you see HTML-Viewer → click it → Add.

To remove it again: download the removal file and double-click it.

Part 2 – Install the PowerPoint add-in “HTML-Viewer”: Mac

Only if you have a Mac. Once per computer. Requires PowerPoint from Microsoft 365.

Step 1: Download the add-in file

Download manifest.xml
  1. Quit PowerPoint (menu PowerPoint → Quit PowerPoint).
  2. Open Finder and press Cmd + Shift + G.
  3. Paste this line and press Enter:
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  4. Is there a folder called wef? If not: right-click → New Folder → name it wef.
  5. Open the wef folder and drag the file manifest.xml from Downloads into it.
  6. Open PowerPoint → tab Home → Add-ins → HTML-Viewer.

Part 3 – Use it

  1. In KNIME: drag the node ECharts View & Export into your workflow and connect it to your table.
  2. Double-click the node → paste your ECharts code (exactly as in the Generic ECharts View) → enter a path at Export-Datei, e.g. C:\Export\chart.json → keep the tick at HTML-Datei speichern → OK.
  3. Run the node. Next to the JSON file you now find chart.html.
  4. In PowerPoint: open a slide → Home → Add-ins → HTML-Viewer.
  5. Drag the frame to the size you want → Choose HTML file … → select chart.html.
  6. Save the presentation. In slide show mode (F5) the chart is interactive.

Good to know: the chart is saved inside your .pptx and is not uploaded anywhere. When opening the presentation, PowerPoint needs internet to load the add-in. Anyone who opens your presentation also needs the add-in (Part 2) – otherwise they see a placeholder.
